Case study 01

The Yard Studio

A collaborative design workspace built around the Howard University community.

Howard students constantly create digital experiences for clubs, events, elections, publications, and campus organizations. The Yard Studio asks what would happen if those experiences were designed in a shared environment that felt like Howard itself.

My roleUX / UI Designer
Project typeHCI + Product Design
Current phaseConcept + early UX definition
FocusCollaboration + campus community
Overview + problem statement

Campus design work is everywhere. The system around it isn’t.

Student organizations often build websites, event pages, recruitment materials, voting experiences, and other digital products in separate tools and isolated files. That fragmentation can make it harder to discover active projects, find collaborators, reuse trusted Howard design assets, or learn from work that has already been done.

The Yard Studio is a concept for one shared design environment where Howard students, student organizations, and departments can discover projects, collaborate, and pull from reusable campus design resources.

How might we create a shared design environment where Howard students can discover projects, collaborate across organizations, reuse trusted campus resources, and contribute to the digital experiences that shape their community?
Discoverability

Make open projects and calls for help visible so skills and needs can find each other.

Consistency

Reduce repeated work with shared components, patterns, and trusted campus design resources.

Belonging

Use familiar campus language and spaces so the product feels built with Howard, not simply placed on top of it.

Organized like the campus itself.

Design principle
Veritas et Utilitas Truth and service — translated into design work that is useful to the campus community.
