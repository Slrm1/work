# Selorm Kalitsi — UX Portfolio

A responsive UX/Product Design portfolio featuring The Yard Studio, AfroLearn, the Sphero Emergency Interface, and Famished.

## GitHub Pages

This site is intentionally static and can be served directly from the repository root with GitHub Pages.

### Publish
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then **Save**.
4. The portfolio will be available at `https://slrm1.github.io/work/`.

## Notes
- The headshot is embedded directly in `index.html`, so the site has no external image dependency.
- The Yard Studio section intentionally labels research/testing as next steps rather than claiming work that has not yet been completed.
