# Selorm Kalitsi — UX Portfolio

A responsive UX/Product Design portfolio featuring **The Yard Studio**, **AfroLearn**, the **Sphero Emergency Interface**, and **Famished**.

## GitHub Pages

The site is already configured with a GitHub Actions deployment workflow.

To turn the public URL on for the first time:

1. Open **Settings → Pages** for this repository.
2. Under **Build and deployment**, set **Source** to **GitHub Actions**.
3. Save the setting.
4. Re-run the latest **Deploy portfolio to GitHub Pages** workflow, or make any new commit.

The portfolio will then publish at:

**https://slrm1.github.io/work/**

## Notes

- The portfolio is a static site in `index.html`.
- Selorm's headshot is embedded into the page, so there is no external image dependency.
- The Yard Studio case study labels interviews, testing, and iteration as next steps rather than presenting unfinished research as completed work.
